# MROJA Eco-Village

Static landing page for MROJA.

## What is included

- Russian one-page landing page in `index.html`
- Responsive styling in `styles.css`
- Interactive tabs, 3D restoration carousel, and share fallback in `script.js`
- Local Horta font and visual assets in `assets/`

## Local preview

Open `index.html` directly in a browser.

## GitHub Pages

This site is ready to publish from the repository root:

1. Push the repository to GitHub.
2. Open repository Settings.
3. Go to Pages.
4. Select the `main` branch and `/root` as the source.
